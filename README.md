A personal technology portfolio showcasing software development, databases, data, cybersecurity, networking, and electronics.

## Overview

This repository contains the source code for my personal portfolio website.

The portfolio serves as a central platform for presenting my technical background, projects, skills, certifications, and professional development.

Beyond its role as a personal portfolio, the website is also an ongoing software development project. It demonstrates the practical application of modern web technologies, component-based architecture, responsive interface design, and iterative software development.

My technical interests and experience span several areas:

- Software Development
- Databases & SQL
- Data

The project is developed with an emphasis on maintainability, reusable components, responsive design, accessibility, and continuous improvement.

## Project Architecture

The LEE Portfolio follows a component-based architecture using Next.js and React.

The application is organised around reusable components and clearly defined website sections. This approach helps keep the code organised, maintainable, and easier to extend.

### Main Components

- **Page Sections** – Organise the website's content, including Hero, What I Do, Projects, Skills, About, and Contact.
- **Navigation** – Provides access to the main sections of the portfolio.
- **ProjectCard** – A reusable component for presenting individual projects.
- **ThemeToggle** – Controls the website's appearance by allowing visitors to select Light, Dark, or System mode.

### Architecture Approach

The project uses the following principles:

- **Component reusability:** Shared interface elements are built as reusable components.
- **Separation of concerns:** Different components are responsible for specific interface functions.
- **Maintainability:** The structure supports easier updates and future development.
- **Scalability:** New sections and functionality can be added as the portfolio grows.

## Development Methodology

The AMZOLELE Portfolio was developed using an **iterative and incremental development approach**.

Development was divided into manageable stages, allowing individual sections and features to be implemented, reviewed, tested, and improved over time.

### Development Process

The general development cycle involved:

1. **Planning** – Identifying the website's requirements, structure, and intended functionality.
2. **Implementation** – Building the interface, components, and features.
3. **Testing** – Checking functionality, responsiveness, and interface behaviour.
4. **Review** – Evaluating the implementation and identifying areas for improvement.
5. **Refinement** – Making adjustments based on testing and review.
6. **Documentation** – Recording important development decisions and project progress.

### Methodology Classification

This project does not strictly follow Test-Driven Development (TDD), where tests are written before the corresponding implementation.

Instead, it follows an iterative development process in which features are built and progressively improved through testing and feedback.

This approach supports continuous improvement while keeping the project manageable.
